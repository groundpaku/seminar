    ・routers
    ・schemas
    ・auth.py
    ・db.py
    ・main.py

# FastAPIのサービス起動
systemctl daemon-reload
systemctl start furuya_api.service
systemctl status furuya_api.service
※activeになっていない場合は、設定ファイル等を見直してください。
systemctl enable furuya_api.service

# Nginxの再起動
systemctl restart nginx.service
systemctl status nginx.service
※activeになっていない場合は、設定ファイル等を見直してください。
